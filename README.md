***SQL:***
SQL (Structured Query Language) is used to define, read, change, and control data in relational databases.

***Table:***
A database contains tables; a table contains rows (records) and columns (fields).

***Use/Purpose Of Databases:***
- Retreving Data from normal files or on papers is difficult if the data is too large, to overcome this we use databases.
- By using databases we can retrieve the data quickly.

SQL commands are divided into different categories based on the operations they perform:

**1. DDL(Data Definition Language):** CREATE, ALTER, DROP, TRUNCATE.

**2. DML(Data Manipulation Language):** INSERT, UPDATE, DELETE.

**3. DQL(Data Query Language):** SELECT.

**4. DCL(Data Conrol Language):** GRANT,REVOKE.

**5. TCL(Transaction Conrol Language):** COMMIT, ROLLBACK, SAVEPOINT.

## Basic terminology:
1. Database: a collection of related data and database objects.
2. Table: data organized into rows and columns.
3. Row: one record in a table.
4. Column: one attribute of a record.
